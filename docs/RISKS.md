# 위험과 주의사항

읽지 않고 쓰다가 문제가 생기는 부분만 모았습니다.

---

## 1. 시험 · 설문 · 토론 (기본 꺼짐)

### 무슨 일이 일어나나

eClass 의 `학습 활동` 아래 시험/설문/토론은 **페이지를 여는 행위 자체가
서버에 기록**됩니다.

| 메뉴 | 열었을 때 생길 수 있는 일 |
|---|---|
| 시험 | **응시 시작으로 기록**. 제한시간이 그 순간부터 흐르기 시작하는 설정이 있습니다. |
| 설문 | 참여로 집계되어 다시 응답하지 못하게 될 수 있습니다. |
| 토론 | 조회 기록이 참여 점수에 반영되는 과목이 있습니다. |

자동화 도구가 새벽 3시에 시험 페이지를 열었다는 로그는, 사정을 모르는
사람이 보면 부정행위 정황으로 읽힙니다.

### 이 도구가 하는 일

```toml
[eclass.risky]
i_understand_the_risk = false   # 이게 true 가 아니면 아래는 전부 무시됨
exam       = false
survey     = false
discussion = false
```

**두 겹의 옵트인**이 필요합니다. 둘 다 켜더라도:

- 목록 페이지의 **제목과 날짜만** 읽어 `시험_목록.md` 같은 파일로 남깁니다.
- **상세 페이지에는 절대 들어가지 않습니다.** (`crawler.py` 의
  `titles_only=True` 경로)

그래도 목록 페이지에 접근한 기록은 남습니다. 완전히 안전하지는 않습니다.

### 권장

켜지 마세요. 시험 일정은 공지사항에 올라오고, 그건 안전하게 수집됩니다.

---

## 2. 출석 · 성적 (수집은 선택, 업로드는 기본 제외)

읽기 전용이라 열어도 기록 문제는 없습니다. 다만 **본인 식별이 되는
민감정보**입니다.

```toml
[eclass.menus]
attendance = false   # 기본 꺼짐
grade      = false   # 기본 꺼짐

[eclass.upload]
exclude_menus = ["grade", "attendance"]   # 켜더라도 업로드는 제외
```

수집은 켜고 업로드는 막는 조합을 기본으로 뒀습니다. 성적을 릴리스에
올리면, 나중에 저장소 접근 권한을 누군가에게 주는 순간 함께 넘어갑니다.

---

## 3. 저작권

### private 저장소를 쓰세요

강의자료(PPT, PDF)와 강의 녹화본의 저작권은 작성자(교수)에게 있습니다.

- **본인이 보려고 받아 두는 것**: 저작권법 제30조 사적이용 복제로
  볼 여지가 있습니다.
- **public 저장소에 올리는 것**: 누구나 받을 수 있게 되므로 사적이용이
  아니라 **공중송신**입니다. 명백한 침해입니다.

이 도구는 저장소가 public 인지 검사하지 않습니다. 사용자 책임입니다.

### 녹화 자체

- 한국 통신비밀보호법상 **본인이 참여한 대화의 녹음은 합법**입니다
  (제3자 간 대화 도청과 다릅니다).
- 하지만 **대학 학칙은 별개**입니다. 많은 학교가 수업 녹화·녹음·배포를
  제한하고, 위반 시 징계 사유가 됩니다.
- 녹화본을 다른 학생에게 주는 순간 사적이용 범위를 벗어납니다.

**담당 교수에게 먼저 물어보세요.** 대부분 허락합니다.

---

## 4. 서버 부담

```toml
[eclass]
request_delay_sec = 1.0   # 0.5 미만으로 내리지 마세요
```

학교 LMS 는 상용 서비스가 아닙니다. 빠르게 반복 요청하면 다른 학생의
수강신청이나 과제 제출에 지장을 줄 수 있고, 차단당할 수 있습니다.

- 수집 주기를 1시간보다 짧게 잡지 마세요. **3시간이면 충분합니다.**
- 세션 쿠키를 저장해 매번 로그인하지 않습니다.
- 로그인 실패 시 **재시도하지 않습니다.** 비밀번호를 여러 번 틀리면
  학교 계정이 잠깁니다.

## 5. 자격증명

| 하지 말 것 | 대신 |
|---|---|
| `config.toml` 에 비밀번호 적기 | `scripts\set_password.bat` |
| `.bat` 파일에 토큰 적기 | 위와 같음 |
| GitHub 토큰에 전체 권한 주기 | `repo` 범위만, 만료일 설정 |

`config.toml` 은 `.gitignore` 에 있지만, `git add -f` 하면 그냥 올라갑니다.
탐색(probe) 결과에는 **학번, 이름, 교수 이메일**이 들어갑니다.
기본적으로 가려서 저장하지만(`--no-redact` 로 끌 수 있음) 커밋하지 마세요.

## 6. 데이터를 잃는 경우

| 상황 | 결과 |
|---|---|
| `container = "mp4"` 로 두고 녹화 중 전원 차단 | 파일 전체가 재생 불가. **mkv 를 쓰세요.** |
| `segment_minutes = 0` 으로 두고 3시간 녹화 중 크래시 | 전부 날아감 |
| `delete_local_after_upload = true` 인데 업로드 실패 | 복구 불가 |
| 오디오 장치 이름을 잘못 적음 | 3시간 무음 녹음 (60초 후 경고 로그는 남습니다) |

마지막 것이 가장 흔합니다. **녹화를 걸기 전에 반드시
`scripts\record_now.bat -m 1` 로 1분 시험 녹화를 해서 소리를 확인하세요.**
