# 위험과 주의사항

읽지 않고 쓰다가 문제가 생기는 부분만 모았습니다.

> **이 문서는 법률 자문이 아닙니다.**
>
> 아래 서술에는 **확인한 것과 확인하지 못한 것이 섞여 있습니다.** 구분을
> 위해 다음 표기를 씁니다.
>
> | 표기 | 뜻 |
> |---|---|
> | `[확인]` | 코드나 실행 결과로 직접 확인함 |
> | `[조문-미확인]` | 법 조문을 인용했지만 **원문을 확인하지 않음.** 믿고 행동하기 전에 직접 보세요 |
> | `[추정]` | 근거 있는 판단이지만 측정하거나 확인한 값이 아님 |
> | `[확인 못함]` | 알아야 하는데 알아내지 못함. 문서 맨 끝 목록 참고 |
>
> 표기가 없는 줄은 이 도구의 동작에 관한 설명입니다.

---

## 1. 시험 · 설문 · 토론 (기본 꺼짐)

### 무슨 일이 일어나나

eClass 의 `학습 활동` 아래 시험/설문/토론은 **페이지를 여는 행위 자체가
서버에 기록**됩니다.

| 메뉴 | 열었을 때 생길 수 있는 일 |
|---|---|
| 시험 | **응시 시작으로 기록**. 제한시간이 그 순간부터 흐르기 시작하는 설정이 있습니다. |
| 설문 | 참여로 집계되어 다시 응답하지 못하게 될 수 있습니다. |
| 토론 | 조회 기록이 참여 점수에 반영되는 과목이 있습니다. |

자동화 도구가 새벽 3시에 시험 페이지를 열었다는 로그는, 사정을 모르는
사람이 보면 부정행위 정황으로 읽힙니다.

### 이 도구가 하는 일

```toml
[eclass.risky]
i_understand_the_risk = false   # 이게 true 가 아니면 아래는 전부 무시됨
exam       = false
survey     = false
discussion = false
```

**두 겹의 옵트인**이 필요합니다. 둘 다 켜더라도:

- 목록 페이지의 **제목과 날짜만** 읽어 `시험_목록.md` 같은 파일로 남깁니다.
- **상세 페이지에는 절대 들어가지 않습니다.** (`crawler.py` 의
  `titles_only=True` 경로)

그래도 목록 페이지에 접근한 기록은 남습니다. 완전히 안전하지는 않습니다.

### 권장

켜지 마세요. 시험 일정은 공지사항에 올라오고, 그건 안전하게 수집됩니다.

## 2. 출석 · 성적 (수집은 선택, 업로드는 기본 제외)

읽기 전용이라 열어도 기록 문제는 없습니다. 다만 **본인 식별이 되는
민감정보**입니다.

```toml
[eclass.menus]
attendance = false   # 기본 꺼짐
grade      = false   # 기본 꺼짐

[eclass.upload]
exclude_menus = ["grade", "attendance"]   # 켜더라도 업로드는 제외
```

수집은 켜고 업로드는 막는 조합을 기본으로 뒀습니다. 성적을 릴리스에
올리면, 나중에 저장소 접근 권한을 누군가에게 주는 순간 함께 넘어갑니다.

---

## 3. 저작권

### private 저장소를 쓰세요

강의자료(PPT, PDF)와 강의 녹화본의 저작권은 작성자(교수)에게 있습니다.

- **본인이 보려고 받아 두는 것**: `[조문-미확인]` 저작권법 제30조
  사적이용 복제로 볼 여지가 있습니다. **조문 원문과 판례를 확인하지
  않았습니다.** 범위를 다투게 되면 이 문장에 기대지 마세요.
- **public 저장소에 올리는 것**: 누구나 받을 수 있게 되므로 사적이용이
  아니라 **공중송신**입니다. 명백한 침해입니다.

이 도구는 저장소가 public 인지 검사하지 않습니다. 사용자 책임입니다.

### 녹화 자체

- `[조문-미확인]` 한국 통신비밀보호법상 본인이 참여한 대화의 녹음은
  제3자 간 대화 도청과 구분된다고 알려져 있습니다. **조문과 판례를
  확인하지 않았습니다.** 그리고 **강의 녹음이 "본인이 참여한 대화"에
  해당하는지는 별개 문제입니다** — 교수의 강의는 대화가 아니라 저작물로
  다뤄질 수 있습니다.
- `[확인 못함]` **군산대 학칙의 수업 녹화 관련 조항을 확인하지
  않았습니다.** 많은 학교가 제한한다고 알려져 있지만, 우리 학교가
  무엇을 어떻게 정해 두었는지는 모릅니다. 직접 확인하세요.
- 녹화본을 다른 학생에게 주는 순간 사적이용 범위를 벗어납니다.

**담당 교수에게 먼저 물어보세요.** 대부분 허락합니다.

## 4. 서버 부담

```toml
[eclass]
request_delay_sec = 1.0   # [추정] 0.5 미만으로 내리지 마세요
```

학교 LMS 는 상용 서비스가 아닙니다. 빠르게 반복 요청하면 다른 학생의
수강신청이나 과제 제출에 지장을 줄 수 있고, 차단당할 수 있습니다.

- `[추정]` 수집 주기를 1시간보다 짧게 잡지 마세요. 3시간이면
  충분합니다. **이 숫자는 측정한 값이 아니라 판단입니다** — eClass 가
  실제로 어느 빈도에서 차단하는지 확인하지 않았습니다.
- 세션 쿠키를 저장해 매번 로그인하지 않습니다.
- `[확인]` 로그인 실패 시 재시도하지 않습니다(`eclass/browser.py`).
  `[확인 못함]` 몇 회에 계정이 잠기는지는 모릅니다.

## 5. 자격증명

| 하지 말 것 | 대신 |
|---|---|
| `config.toml` 에 비밀번호 적기 | `scripts\set_password.bat` |
| `.bat` 파일에 토큰 적기 | 위와 같음 |
| GitHub 토큰에 전체 권한 주기 | `repo` 범위만, 만료일 설정 |

`config.toml` 은 `.gitignore` 에 있지만, `git add -f` 하면 그냥 올라갑니다.
탐색(probe) 결과에는 **학번, 이름, 교수 이메일**이 들어갑니다.
기본적으로 가려서 저장하지만(`--no-redact` 로 끌 수 있음) 커밋하지 마세요.

## 6. 데이터를 잃는 경우

| 상황 | 결과 |
|---|---|
| `container = "mp4"` 로 두고 녹화 중 전원 차단 | 파일 전체가 재생 불가. **mkv 를 쓰세요.** |
| `segment_minutes = 0` 으로 두고 3시간 녹화 중 크래시 | 전부 날아감 |
| `delete_local_after_upload = true` 인데 업로드 실패 | 복구 불가 |
| 오디오 장치 이름을 잘못 적음 | 3시간 무음 녹음 (60초 후 경고 로그는 남습니다) |
| `[추정]` 디스크가 가득 참 | 녹화가 중간에 끊기고, 이후 세그먼트가 생기지 않습니다. 1시간에 수백 MB ~ 수 GB 가 쌓이는데(실측 전), `delete_local_after_upload = false` 면 계속 남습니다 |
| 감시 트리거가 폭주 | ffmpeg 가 즉시 죽는 상황에서 빈 폴더를 양산합니다. 3회 연속 실패하면 멈추도록 막아 두었습니다(`recorder/watcher.py`) |

마지막 것이 가장 흔합니다. **녹화를 걸기 전에 반드시
`scripts\record_now.bat -m 1` 로 1분 시험 녹화를 해서 소리를 확인하세요.**

## 확인 못함 — 이 목록의 항목을 근거로 쓰지 마세요

알아야 하는데 알아내지 못한 것들입니다. **"아마 이럴 것이다"로 메우지
않고 모르는 채로 적어 둡니다.** 확인되면 위 본문으로 올리고 여기서
지웁니다.

| 항목 | 왜 중요한가 | 확인 방법 |
|---|---|---|
| 군산대 학칙의 수업 녹화·녹음 조항 | 녹화 기능 전체의 전제 | 학칙 원문 또는 학사지원과 문의 |
| eClass 이용약관의 자동 수집 허용 여부 | 수집 기능 전체의 전제 | eClass 약관 페이지 |
| 로그인 몇 회 실패에 계정이 잠기는지 | 잠기면 수업에 지장 | 학교 전산원 문의 (직접 시험하지 마세요) |
| eClass 가 **시험·설문 목록 페이지** 접근까지 기록하는지 | 목록만 읽는 설계의 안전성 근거 | 확인 수단 없음. 그래서 기본 비활성 |
| 저작권법 제30조의 실제 범위 | 수집·보관의 적법성 | 조문 원문과 판례 |
| 1시간 녹화의 실제 용량 | 디스크 계획 | `record_now.bat -m 1` 로 1분 재고 60배 |
| 전사 1시간 분량의 실제 소요 시간 | 배터리·일정 판단 | `transcribe queue` 가 자동 측정합니다(`perf.py`) |
| GitHub Actions 경로에서 학교가 해외 IP 를 막는지 | 클라우드 수집 가능 여부 | Actions 에서 `dry_run=true` 로 1회 실행 |

### 검증하지 못한 기능

테스트 456개는 전부 Linux 컨테이너에서 가짜 장치로 돌린 것입니다.
**아래는 Windows 실기에서 확인하지 않았습니다.**

- `gdigrab` 화면 캡처 (다중 모니터·배율·HDR 포함)
- WASAPI 루프백으로 **실제 소리가 녹음되는지** — 사람이 들어야 압니다
- 작업 스케줄러 등록·실행, 잠금 화면에서의 동작
- `.bat` / `.vbs` 의 실제 동작 (셸·경로에 공백·한글이 있을 때)
- faster-whisper 의 실제 전사 품질 (특히 숫자·사람 이름·전공 용어)
- eClass 실제 로그인과 수집

**자동 실행을 걸기 전에 `scripts\record_now.bat -m 1 --no-upload` 로
1분 녹화를 돌려 소리가 들어갔는지 반드시 확인하세요.**
